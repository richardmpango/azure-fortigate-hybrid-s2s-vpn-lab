# Security and redaction notes

This repository is intended for public portfolio use.

The published screenshots intentionally redact or omit:

- Azure subscription identifiers
- Internet-facing IP addresses
- FortiGate serial number
- VPN pre-shared keys and credentials

Internal RFC1918 lab addresses are retained because they help explain the network architecture and do not expose routable Internet endpoints.

Before publishing future screenshots, review them for credentials, access keys, tokens, tenant identifiers, public IP addresses, device serial numbers, and billing information.
